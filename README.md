# FLOODGUARD AI — Flood-risk research prototype

A beginner-friendly, iPhone-compatible Python project that demonstrates a machine-learning workflow and a Streamlit dashboard.

## Important scientific limitation

The included model is trained on **synthetic demonstration data** generated by `src/generate_demo_data.py`. The artificial labels are produced by a simple teaching rule. This lets the software run end-to-end, but it does **not** make the model a real flood predictor.

Do not use the score for evacuation, emergency response, public warnings, or any real-world safety decision. Do not present demo metrics as real-world accuracy.

A genuine research version must use verified, documented historical flood observations and environmental measurements, perform time- and location-separated validation, and be independently reviewed.

## Project contents

- `app.py` — Streamlit web dashboard.
- `src/generate_demo_data.py` — generates synthetic demonstration data.
- `src/train_model.py` — trains and evaluates a Random Forest pipeline.
- `data/` — generated demo CSV appears here after running the generator.
- `models/` — trained model file appears here after training.
- `reports/` — demo metrics JSON appears here after training.
- `requirements.txt` — Python packages.

## Deploy through Streamlit Community Cloud

1. Push the project files to a GitHub repository.
2. Open https://share.streamlit.io/
3. Connect GitHub.
4. Select the repository and `app.py` as the main file.
5. Deploy. Streamlit installs packages from `requirements.txt`.

Deployment options and free-tier limits may change. The app may need to train the small demo model at first launch.

## Input definitions

- `rainfall_24h_mm`: rainfall total over 24 hours in millimetres.
- `rainfall_72h_mm`: rainfall total over 72 hours in millimetres.
- `river_level_m`: observed river level in metres.
- `river_capacity_m`: reference river capacity in metres.
- `soil_saturation_pct`: soil saturation percentage.
- `elevation_m`: elevation above a local reference, in metres.
- `drainage_score`: illustrative drainage score from 0 (poor) to 100 (good).

For a real study, these variables need precise operational definitions, trustworthy sources, consistent units, and documented measurement times.
